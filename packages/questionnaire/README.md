# @webforge/questionnaire

Structured questionnaire and requirements gathering engine for WebForge.

## Responsibility

`@webforge/questionnaire` manages the structured questions presented to users/builders to extract their domain requirements, dependencies, and configuration.

## Planned Features

- **Question Definitions**: Type-safe declarations for questions, prompts, validation rules, and choices.
- **Conditional Questions**: Logic trees that conditionally ask follow-ups based on earlier answers.
- **Dependencies**: Rules dictating question dependencies and module triggers.
- **Defaults**: Intelligent domain defaults based on project category.
- **Answer Resolution**: Normalization of user answers ready for `@webforge/compiler`.

## Status

**Scaffolding only.** Questionnaire schemas and evaluation logic will be implemented in future phases.
