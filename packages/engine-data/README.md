# @webforge/engine-data

Generic data engine for WebForge applications.

## Responsibility

`@webforge/engine-data` handles data persistence, generic querying, validation, filtering, sorting, pagination, transactions, and relationship resolution purely driven by the declarative `AppSpec`.

## Planned Features

- **Entity Management**: Schema mapping and data modeling.
- **Validation**: Strict boundary validation using AppSpec field rules and types.
- **Generic CRUD**: Unified interface for Create, Read, Update, and Delete operations.
- **Relationships**: Automatic management of 1:1, 1:N, and N:M relations.
- **Query Engine**: Dynamic filtering, multi-field sorting, and pagination.
- **Transactions**: Atomic multi-entity mutations and rollbacks.

## Status

**Scaffolding only.** The generic data engine will be implemented in future phases.
