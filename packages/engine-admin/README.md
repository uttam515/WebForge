# @webforge/engine-admin

Auto-generated admin dashboard engine for WebForge applications.

## Responsibility

`@webforge/engine-admin` automatically constructs full-featured administration portals and dashboards from the `AppSpec` data entities and permissions.

## Planned Features

- **Data Tables**: Searchable, filterable, sortable data grids.
- **Forms**: Entity creation and editing forms.
- **Search & Filters**: Multi-field querying and filter presets.
- **Bulk Operations**: Batch actions (status updates, deletion, export).
- **Navigation**: Role-gated admin sidebars and top bars.

## Status

**Scaffolding only.** The admin dashboard generator engine will be implemented in future phases.
