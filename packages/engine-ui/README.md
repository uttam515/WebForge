# @webforge/engine-ui

Generic UI rendering engine, block registry, and view components for WebForge.

## Responsibility

`@webforge/engine-ui` renders pages, layouts, forms, and block trees dynamically based on the declarative `AppSpec`.

## Planned Features

- **Page Renderer**: Recursive layout and block composition tree rendering.
- **Block Registry**: Reusable visual building blocks (containers, typography, hero sections, media).
- **Field Registry**: Form inputs mapped directly to AppSpec field data types.
- **Entity Lists & Details**: Out-of-the-box data presentation components (tables, cards, detail views).
- **Forms**: Declarative form generation with instant validation.
- **Themes**: Design token injection and responsive styling system.

## Status

**Scaffolding only.** UI components and renderer will be implemented in future phases.
