# @webforge/modules

Functional capability modules for WebForge applications.

## Responsibility

`@webforge/modules` houses self-contained, modular application capabilities that can be selected, configured, and composed into an AppSpec.

## Planned Modules

- **Authentication**: User management, credentials, OAuth, session management.
- **E-Commerce**: Products, collections, inventory, cart, checkout, orders.
- **Events**: Schedules, venues, ticketing, and RSVPs.
- **Blog / CMS**: Articles, authors, categories, tags, publishing workflows.
- **Media Gallery**: Asset management, uploads, galleries.
- **Registration / Onboarding**: Forms, multi-step onboarding, verification.

## Status

**Scaffolding only.** Capability modules will be developed in future phases.
